# CrazyZerg — Game Design Document

## Overview

**Жанр:** 3D Action-Survival с roguelite-элементами
**Движок:** Three.js + TypeScript + Vite
**Визуальный стиль:** Low-poly стилизация

**Концепция:** Игрок управляет Guardian'ом (летающий зерг) от третьего лица. Волны терранов (марины + элитные юниты) атакуют со всех сторон. Цель — продержаться как можно дольше, используя рельеф местности и прокачку между волнами.

---

## Core Loop

1. **Бой** — отбиваешь волну маринов, маневрируя и используя high ground
2. **Передышка** — между волнами выбираешь одно улучшение из 3 случайных
3. **Эскалация** — следующая волна сильнее, появляются элитные юниты
4. **Game Over** — здоровье на нуле, показываем статистику (волна, убийства, время)

---

## Управление

- **WASD** — горизонтальное движение
- **Колёсико мыши** — высота полёта
- **ЛКМ** — выбрать приоритетную цель (иначе автоатака по ближайшему)
- **Камера** — следует за Guardian'ом сзади-сверху (third-person)

---

## Боевая система

### Guardian (игрок)

- Базовая атака: кислотные споры — медленные, но мощные снаряды по области
- Автоматически атакует ближайшего врага каждые ~2 сек
- ЛКМ по врагу — фокусировка огня на этой цели
- Здоровье: ~500 HP, нет регенерации по умолчанию

### Враги

| Юнит | HP | Урон | Особенность |
|------|-----|------|-------------|
| **Марин** | 40 | 6/сек | Базовый враг, стреляет с земли |
| **Медик** | 60 | 0 | Лечит маринов, приоритетная цель |
| **Файрбат** | 80 | 15/сек | Ближний бой, высокий урон, медленный |
| **Гоуст** | 50 | 10/сек | Локдаун (стан на 2 сек), редкий |

### High Ground механика

- Guardian на высоте +10м и выше: **+25% урона**, **+20% дальности атаки**
- Враги на низине: **-15% точность** по Guardian'у
- Бонусы суммируются — позиция критически важна

## Карта

**Арена:** Скалистое плато ~200x200 метров

### Структура рельефа

- **Центральная возвышенность** — главная high ground точка, но открыта со всех сторон
- **4 скальных гряды** по периметру — естественные укрытия, можно разделять группы врагов
- **2 каньона** — узкие проходы между скалами, враги идут плотной группой (удобно для AoE)
- **Низины между холмами** — опасные зоны, здесь Guardian уязвим

### Точки спавна врагов

- 4 точки по краям карты (север/юг/запад/восток)
- Волна 1-3: одна точка
- Волна 4-7: две точки
- Волна 8+: все четыре точки

### Высоты

- Низина: 0м (базовый уровень)
- Холмы/гряды: 10-15м
- Центральная возвышенность: 20м
- Максимальная высота полёта Guardian'а: 30м

### Визуал (low-poly)

- Камни/скалы — серо-коричневые
- Земля — пустынная, песочно-жёлтая
- Креп (zerg creep) — фиолетовые пятна для атмосферы

## Система прокачки (Roguelite)

### Механика

- После каждой волны — пауза 5 сек
- Появляется меню с 3 случайными улучшениями
- Выбираешь одно, остальные исчезают
- Улучшения накапливаются до конца игры

### Пул улучшений

| Категория | Улучшение | Эффект |
|-----------|-----------|--------|
| **Урон** | Кислотные железы | +15% урона |
| | Разъедание | Атаки снимают броню (-10% защиты врага) |
| | Двойной плевок | 2 снаряда вместо 1 (50% урона каждый) |
| **Защита** | Толстый панцирь | +50 HP |
| | Регенерация | +5 HP/сек между волнами |
| | Уклонение | 10% шанс избежать урона |
| **Мобильность** | Быстрые крылья | +20% скорость движения |
| | Вертикальный рывок | Пробел = быстрый подъём на 10м |
| | Парение | Меньше теряешь высоту со временем |
| **Способности** | Ядовитое облако | Каждые 15 сек — AoE урон вокруг |
| | Паразит | Убитый враг лечит на 10 HP |
| | Берсерк | Ниже HP = выше урон (до +50%) |

### Редкость

- Обычные: 70%
- Редкие: 25%
- Эпические: 5%

## Техническая архитектура

### Стек

- **Three.js** — 3D рендеринг
- **TypeScript** — типизация
- **Vite** — сборка и dev server

### Структура проекта

```
src/
├── main.ts              # Точка входа
├── game/
│   ├── Game.ts          # Главный класс, game loop
│   ├── World.ts         # Карта, рельеф, освещение
│   └── WaveManager.ts   # Спавн волн, сложность
├── entities/
│   ├── Guardian.ts      # Игрок
│   ├── Marine.ts        # Базовый враг
│   ├── Medic.ts         # Лечит врагов
│   ├── Firebat.ts       # Ближний бой
│   └── Ghost.ts         # Локдаун
├── systems/
│   ├── InputSystem.ts   # WASD + мышь
│   ├── CombatSystem.ts  # Урон, автоатака, high ground
│   ├── AISystem.ts      # Поведение врагов
│   └── UpgradeSystem.ts # Roguelite прокачка
├── ui/
│   ├── HUD.ts           # HP, волна, счёт
│   └── UpgradeMenu.ts   # Выбор улучшений
└── utils/
    └── helpers.ts       # Математика, рейкасты
```

### Game Loop

1. Input → обновить позицию Guardian'а
2. AI → враги двигаются/атакуют
3. Combat → обработка урона, смерти
4. Render → отрисовка кадра

### Производительность

- Object pooling для врагов и снарядов
- Frustum culling (Three.js автоматически)
- Low-poly модели < 500 полигонов каждая
